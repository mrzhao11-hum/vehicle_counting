# 无人机轻量级密度图车辆计数：研究与实施路线

更新时间：2026-09-18。

本文是研究执行方案，不代表车辆训练代码已经完成，也不保证专利受理、授权或论文录用。公式、超参数和时间安排属于拟实施方案，应通过训练集、验证集和实际实验确定。

## 1. 最终建议与任务边界

推荐题目方向：面向无人机视角的小目标尺度感知蒸馏车辆计数。

先在 CARPK 跑通模型，再在 UAVDT 做道路主实验；两个数据集分别训练、分别测试。最后增加跨数据集测试和少量真实高架道路验证。不要把“UAVDT 训练后直接测 CARPK”作为唯一实验。

核心任务是输入一张无人机图像，输出车辆密度图，对像素求和得到当前画面中的车辆数量。视频阶段逐帧执行这一过程。模型不直接输出框、车辆身份、速度，也不自动统计累计通过车辆数。

第一版使用完整 CSRNet 作为教师、通道缩减的 quarter-CSRNet 作为学生，沿用现有 SKT 的骨架。重点改造标签与训练损失，暂不同时替换骨干、增加道路分割或引入跟踪系统。

候选贡献是：由同一套车辆尺度信息联合控制密度核、密度监督权重和局部特征蒸馏权重，使有限容量的学生更关注小车辆，同时限制权重上界并保留背景惩罚。是否有足够新颖性，需要进一步检索；是否有效，需要实验验证。

## 2. 专利与论文两个目标分别需要什么

### 专利申请目标

受理是申请程序环节，不是创新性认可，更不是授权。2023 年修订的实施细则第四十三、四十四条规定了申请日、申请号和不予受理等事项；专利法第二十二条规定授权所需的新颖性、创造性、实用性，第二十六条要求清楚、完整说明技术方案。

依据：[专利法实施细则](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)、[专利法](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)。

建议按发明专利方向与学校知识产权部门或代理师沟通，不将算法方法简单包装成实用新型。先确认学校要求的是受理通知书、公开还是授权，以及申请人、发明人和费用办理规则。

为准备一份可实施的交底书，本项目建议至少完成：真实标签转换和核验、教师与学生训练、一组基础对照、一组完整改进模型、实际测得的数量和时间结果，以及方法流程图。这是本项目的工作建议，不是受理环节法定要求完成训练实验。

申请文件通常包括请求书、说明书、权利要求书、摘要及必要的附图。提交后依通知办理费用和补正，不将申请号当作已经授权的专利号。参考：[国家知识产权局申请说明](https://www.cnipa.gov.cn/art/2020/6/5/art_1517_92472.html)。

先由学校或代理师检索并确认申请方案，再正式提交；公开论文预印本、代码及含完整方案的公开报告应安排在提交之后，并与代理师确认保护范围。公开前内容可能构成现有技术，不应依赖一般性的“六个月宽限期”。依据：[专利法第二十二、二十四条](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)。

### 小论文目标

建议争取两个公开数据集的同域实验、逐模块消融、至少一个车辆专项轻量方法对照，以及同一硬件上的速度测试。主张小目标改进时，还要提供小目标占比较高场景的独立结果。

不要求所有指标都超过所有方法，但应显示稳定、明确的准确率与效率收益。若改进在重复实验中不稳定，先调整方法或缩小结论，不应仅凭一张较好热力图写成有效创新。

## 3. 从头阅读论文：顺序与每篇产出

每篇先读摘要、方法图、实验结论，再精读方法和实现细节，最后回到相关工作追踪相近研究。不要等读完所有论文才动手，阅读与小规模数据处理同步进行。

建议每篇写一页笔记，固定记录：任务、输入输出、标签构造、结构、损失、数据划分、指标、可复用部分、与拟方案重合部分、尚未理解的问题。

### 第一篇：CSRNet，CVPR 2018

题目：CSRNet: Dilated Convolutional Neural Networks for Understanding the Highly Congested Scenes。

[论文与 PDF 入口](https://openaccess.thecvf.com/content_cvpr_2018/html/Li_CSRNet_Dilated_Convolutional_CVPR_2018_paper.html)。

目标：理解现有计数骨架。重点看 VGG 前端、空洞卷积后端、密度图监督和计数求和。论文也包含 TRANCOS 车辆计数实验，但无人机道路数据仍需自行验证。

对照代码阅读：`models/model_vgg.py`、`image.py`、`dataset.py`、`test.py`。

本阶段产出：画出图像到密度图的结构，标出特征尺寸；说明模型为何不输出 bbox；说明密度图降低分辨率时为什么必须保持总和。不要机械照搬人群数据的核参数。

### 第二篇：SKT，ACM Multimedia 2020

题目：Efficient Crowd Counting via Structured Knowledge Transfer。

[论文](https://arxiv.org/abs/2003.10120)、[作者代码](https://github.com/HCPLab-SYSU/SKT)。

目标：理解当前项目的教师、学生、层内模式迁移和跨层关系迁移。分别追踪硬标签监督、教师输出监督和中间特征损失。

对照代码阅读：`models/model_teacher_vgg.py`、`models/model_student_vgg.py`、`models/distillation.py`、`SKT_distill.py`。

本阶段产出：写清楚教师何时训练、何时冻结；学生通道为何变少；通道对齐层如何使用；哪种损失是空间图，哪种损失已聚合为关系矩阵。

当前实现中关系计算有取第一个 batch 样本的写法，蒸馏入口也固定 batch=1。第一版可保留单卡 batch=1；扩大 batch 前必须修复并核验关系计算。科研版本还应把当前训练循环里反复测试的行为改为验证集选模型、最后独立测试。

### 第三篇：GhostCount，IET Intelligent Transport Systems 2023

题目：GhostCount: A Lightweight Convolution Network Based on High-Altitude Video for Vehicle Instantaneous Counting in Dense Traffic Scenes。

[开放全文](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/itr2.12318)。

目标：学习与车辆任务直接相关的轻量编码解码、特征融合、背景抑制和效率评估。重点阅读标签生成、结构图、损失和核参数实验。

本阶段产出：记录各数据集核参数与处理方式；列出同条件复现需要的设置；把它作为一个车辆轻量对照，而不是立即把所有模块加入学生。

该文在 TRANCOS 的核参数比较中，固定核优于其采用的自适应核。这不是对所有 bbox 自适应核的否定，但说明“自适应必然更好”不能作为前提。

### 第四篇：EdgeCount，IEEE TCSVT

题目：A Lightweight Object Counting Network Based on Density Map Knowledge Distillation。2024 年在线发表，正式卷期为 2025 年。

[作者高校论文页面及全文入口](https://bura.brunel.ac.uk/handle/2438/29929)。

目标：理解更近期的密度图蒸馏和轻量多尺度融合。它是通用目标计数工作，不应把所有结论都直接套用为道路车辆结论。

本阶段产出：区分输出蒸馏和 SKT 特征关系蒸馏；记录真实部署输入尺寸、设备和延迟协议；检查下载版本与正式摘要有无差异，引用最终出版信息。

### 第五篇：加权知识蒸馏，Scientific Reports 2025

题目：Crowd Counting at the Edge Using Weighted Knowledge Distillation。

[开放全文](https://www.nature.com/articles/s41598-025-90750-5)。

目标：学习教师预测可靠性加权，以及 CARPK 上的车辆蒸馏实验。重点看权重由什么量计算、作用于哪个损失、是否使用空间位置或框尺寸。

本阶段产出：写一张区别表。该文根据教师预测误差调整权重；拟方案依据 bbox 尺度生成空间权重。差异可以成为研究切入点，但“依据不同”本身不保证创造性。

### 必须补充的相关工作检索

已有车辆研究将高斯 sigma 设置为框尺寸的函数。例如 [Unsupervised Vehicle Counting via Multiple Camera Domain Adaptation 的实验设置](https://ceur-ws.org/Vol-2659/ciampi.pdf)描述了根据车辆框长度构造高斯核。因此 bbox 转点、尺度高斯核、保存 HDF5 都不能直接写成首次提出。

继续检索关键词：vehicle counting / density map / box adaptive Gaussian / scale-aware distillation / small object weighted loss / foreground distillation。中文检索：车辆计数、密度图、尺度感知、知识蒸馏、小目标加权。

检索范围包含论文和专利。记录最接近工作的公式、权重定义、作用层级和差异，不只记录标题。近期还出现了尺度感知路由蒸馏研究，应进一步检查与拟方法的重合：[相关论文入口](https://www.mdpi.com/2072-4292/18/17/2939)。本次仅检索到该工作，未完成其全文审读。

## 4. 数据集安排与计数口径

### CARPK：先跑通与基准比较

[官方页面](https://lafi.github.io/LPN/)提供无人机停车场图像与车辆框标注。按下载包中的官方训练、测试列表组织；如果没有验证列表，从训练部分按场景或拍摄片段分组留出验证数据，并固定名单。

使用 CARPK 训练自己的教师和学生，再在 CARPK 测试集评估。和论文数字比较前，核对是否同划分、同训练数据、同测试协议。若比较方法使用不同额外数据，应分组列出，不直接声称公平超过。

### UAVDT：道路主实验

[官方页面](https://sites.google.com/view/daweidu/projects/uavdt)包含 UAVDT-Benchmark-M dataset、DET/MOT toolkit 和属性信息。先核对解压后真实 GT 的格式、类别、忽略文件和官方序列划分，不能套用 VisDrone 的列定义。

图像是视频帧，按序列分组划分。从官方训练序列中划验证序列，测试序列保持独立。若抽帧，训练部分可先按固定间隔抽取以减少冗余，必须记录规则；正式测试固定评估帧名单，不能择优抽帧。

第一轮跨 CARPK/UAVDT 实验统一为 car-only；UAVDT 的完整道路实验可以再合并 car、truck、bus。统一口径不代表 CARPK 已标注所有这三类车辆，原始标签范围必须分别说明。

### 自摄数据：最终验证

建议选择不同道路、拍摄高度和车辆密度的少量独立图片，人工核对真实数量。初期只做数量标注即可验证计数；想验证尺度权重或后续微调时再标 bbox。

例如先做 50-100 张间隔采样图片，这是工作量建议，不是足以证明广泛泛化的统计保证。按视频或拍摄场次分组，保留实际失败样本。

### 三种实验严格分开

| 实验 | 训练 | 调参 | 测试 | 结论范围 |
| --- | --- | --- | --- | --- |
| 同域 | CARPK 或 UAVDT 训练部分 | 同数据集验证部分 | 同数据集独立测试部分 | 本数据集效果 |
| 零样本跨域 | UAVDT 训练部分 | UAVDT 验证部分 | CARPK 测试部分 | 未见场景直接泛化 |
| 微调迁移 | UAVDT 后用 CARPK 训练部分微调 | CARPK 验证部分 | CARPK 测试部分 | 目标域适配效果 |

零样本跨域测试不得使用 CARPK 图像训练、标签调参或目标域统计归一化。若使用目标域无标签图像适配，也必须单独命名为域适配实验。

## 5. 数据转换：先正确，再考虑改进

先把各数据集原始框统一为 `x1, y1, x2, y2, category`。保留原始文件，同时生成内部清单，记录图像路径、标签路径、split、sequence、宽高、有效框和真实数量。

处理顺序：解析标注 -> 筛类别和无效框 -> 按明确规则处理越界框 -> 同步图像缩放或裁剪 -> 生成密度和权重。每个被丢弃的框记录原因。忽略区域可能含未逐个标注车辆，不能简单当成零密度背景训练。

框中心为 `cx=(x1+x2)/2`、`cy=(y1+y2)/2`，宽高为 `bw=x2-x1`、`bh=y2-y1`。若原始框是左上角加宽高，应先转换，避免混用格式。

### 固定核基线

每个车辆中心生成一个截断高斯核，并在图像可见范围内归一化到 sum=1。所有实例累加为密度图 D，满足 `D.sum() ~= count`。边缘车辆、重复中心点、零车辆图像均应正确处理。

### bbox 尺度核候选

拟使用 `sigma_x=clip(alpha_x*bw, sigma_min, sigma_max)` 和 `sigma_y=clip(alpha_y*bh, sigma_min, sigma_max)`。第一版可先用等方向核简化，然后把各向异性核作为可选实验。

候选起点可设 alpha=0.2 或 0.25，但只能作为验证集搜索起点，sigma 上下限必须对应实际图像/密度图分辨率。框宽高不等于真实可见车辆尺寸，遮挡、截断和标注误差也会影响核。

重要：高斯核面积归一化仍是 1，不能因为小车辆权重高就把其 density 总和改成 2 或 3。权重图与密度图分开保存。

### 小目标空间权重候选

在固定预处理尺度下，以训练集框面积中位数为 A_ref，定义 `a_i=clip(sqrt(A_ref/A_i), 1, a_max)`，其中 A_i 为正的车辆框面积。A_ref 只从训练集计算，不使用验证/测试标签统计。

以每个实例核的峰值归一化图 H_i 构造 `W=clip(1+beta*sum((a_i-1)*H_i), 1, W_max)`。这样小车辆附近权重较高，背景仍是 1，重叠权重不会无限增长。beta=1、a_max=3、W_max=3 可作为试验起点，不是最优参数结论。

先与更简单的“小框区域权重=2，其他=1”比较。还需加一个所有车辆前景均加权的对照，分辨收益来自小目标尺度还是普通前景强化。

建议 HDF5 保存 `density`、`weight`、`valid_mask`、`count`，另用属性记录版本和生成参数。保留 bbox 信息于清单，后续评估和变换仍需要它。

密度图与权重图缩放规则不同：D 的重采样需保总量；W 是重要性值，不按车辆数量重新归一化；valid_mask 按明确掩码规则变换。裁剪时优先裁图并变换框后重新生成核，避免直接裁已有高斯图导致边缘计数含糊。

验收：随机画至少 20 张 bbox、中心点、密度图和权重图；逐图核验 `abs(D.sum()-count)` 处于数值容差；确认三个 split 无同图、UAVDT 无跨 split 的同序列。

## 6. 工程实现顺序

建议在独立车辆工程目录实现，通过配置区分数据集、核参数和实验条件。现有源码作为基础和复现参照。

| 模块 | 需要完成的功能 | 验收 |
| --- | --- | --- |
| 数据适配器 | CARPK、UAVDT GT 解析成统一框 | 框图与数量人工核验 |

环境沿用已验证的 Python 3.10/PyTorch 2.x；先单 GPU，再扩大训练。记录 Python、PyTorch、CUDA runtime 和驱动版本，训练阶段不同时升级环境。

## 7. 教师与学生训练

### 教师

从 ImageNet 骨干初始化或随机初始化完整 CSRNet，在车辆训练集监督训练。ImageNet 初始化来源要与所有对照一致。已有人群权重若用于初始化，属于不同预训练条件，应明确说明。

先用普通密度损失，验证集 MAE 选择 best checkpoint。基础 sanity check 是对 10-20 张训练图片能明显拟合；失败时先查图像/标签对齐、密度总和、输出尺寸和梯度，再跑全量。

### 学生

先独立训练 quarter-CSRNet，得到 no-KD 基线。随后加载同核配置教师并冻结，teacher.eval() 且不计算教师梯度，师生输入同一处理后的图像。

加权密度监督候选：`L_den=sum(M*W*(D_s-D_gt)^2)/(sum(M*W)+eps)`。M 为有效区域掩码。

加权输出蒸馏候选：`L_out=sum(M*W*(D_s-D_t)^2)/(sum(M*W)+eps)`，教师输出 detach。

第 l 层加权特征蒸馏候选：先通过通道对齐层得到师生可比特征，在通道维计算每个空间位置的余弦距离 E_l，再计算 `L_feat_l=sum(M_l*W_l*E_l)/(sum(M_l*W_l)+eps)`。

W_l 和 M_l 按特征分辨率独立调整；小目标在粗层可能消失，需观察权重可视化和梯度分布。空间权重应在聚合前作用，不是对已聚合的标量损失随意乘图。

第一版跨层 FSP 关系损失保留原始形式，不声称它已被空间加权；若继续加权，需要重新定义空间聚合、归一化和跨层分辨率对齐。

总损失可写为 `L=L_den+lambda_out*L_out+lambda_feat*sum(L_feat_l)+lambda_rel*L_rel`。这是候选方法定义，系数要根据归一化后量级和验证结果选择。

从原始 sum-MSE 切到上述归一化损失时，所有对应对照同步使用同一 reduction。记录分项损失，不直接照搬旧版系数，否则可能只是整体梯度尺度变化导致收益。

推理只保留学生需要的部分；训练期特征对齐层和教师不用参与视频计数。报告部署参数量和训练参数量时注明区别。

## 8. 实验矩阵：避免教师变化混淆结论

先训练 T_fixed 和 T_bbox 两个普通监督教师。每种核条件下的学生实验都使用相应固定教师。先不改变教师损失，隔离学生权重机制收益；最终再单独验证教师也使用权重的版本。

| 编号 | 标签核 | 学生训练方式 | 对应教师 | 用途 |
| --- | --- | --- | --- | --- |
| B0 | 固定 | 完整教师普通监督 | 无 | 精度与效率参照 |
| B1 | 固定 | 轻量学生无 KD | 无 | 结构压缩代价 |
| B2 | 固定 | 原始 SKT | T_fixed | 基础蒸馏效果 |
| B3 | bbox | 原始 SKT | T_bbox | 核变化整体影响 |
| B4 | 固定 | SKT + 加权密度监督 | T_fixed | 独立检查监督权重 |
| B5 | bbox | SKT + 加权密度监督 | T_bbox | 尺度标签与监督组合 |
| B6 | bbox | B5 + 加权输出/特征蒸馏 | T_bbox | 主要候选方法 |
| B7 | bbox | 与 B6 相同 | bbox 加权监督教师 | 教师加权的额外贡献 |

B2 与 B3 的差异同时包含教师和标签变化，因此不宣称它是纯学生机制的消融。若核变化有效，再补 bbox 无 KD 学生和对应教师指标；若加权蒸馏有效，拆分输出与特征加权两项。

另比较所有前景统一加权与尺度加权；必要时添加教师可靠性加权作为相近方法对照。正向收益要在相同训练预算和预训练条件下评估。

CARPK 先用单 seed 发现实现问题，核心 B2/B6 等最终比较建议至少 3 个 seed，报告均值和标准差。UAVDT 同样保留关键对照。对视频帧不把高度相关的每一帧当作独立样本做夸大的显著性结论，可补按序列统计。

## 9. 评估怎么做才能支撑论文

逐图预测数为 D_pred.sum()。MAE 是逐图绝对误差均值；RMSE 是逐图误差平方均值再开根号，不能与未开根的 MSE 混用。计算指标时使用浮点计数，展示时可另列取整数量。

数量总误差可能因漏计和误计抵消。推荐补充按固定网格积分的局部计数误差，如 GAME。若用框中心分配局部真实数，需明确边界规则；密度核积分与中心点真值存在边界差异，不能在方法间改变指标定义。

不能凭密度图峰值直接报告车辆检测 recall、AP 或“小车辆逐个检出率”。第一版可以按图像的小框占比划组、按车辆数量划密集程度组，报告各组计数 MAE/RMSE。阈值从训练集确定后冻结，测试标签仅用于最终分组评估。

至少保存：逐图 GT/预测/误差 CSV、配置、数据划分名单、seed、checkpoint、损失曲线、代表性成功和失败可视化。密度热力图应说明色标归一化，不能只看颜色深浅比较准确率。

同一 GPU、相同输入尺寸、batch=1、相同精度下测试网络延迟。先 warm-up，再重复测量，CUDA 测时同步，报告 median 或 mean 及波动。单独报告网络前向与包含读取、预处理的端到端延迟。

统一 FLOPs 或 MACs 的计数约定并记录输入尺寸；原始分辨率变化时同时报告真实图像延迟。4090 上运行快不代表无人机端实时，未测边缘设备时只说轻量模型和服务器推理效率。

## 10. 对照论文与撰写方式

最低工作对照是完整教师、同结构学生无 KD、原始 SKT 和完整候选方法。争取论文时，再复现 GhostCount 或其他公开可复现的车辆轻量方法；若无法复现，就明确区分引用数字与自行测得数字。

CARPK 同域结果可以和同协议方法比较。UAVDT 的计数实验不是其原始检测指标：自己固定计数协议，说明类别、忽略规则、划分和抽帧，不能把 MAE 和检测 AP 混在同一排名中。

论文围绕一个问题组织：通道压缩后的学生在小车辆占比较高场景中丢失计数信息，尺度信息联合监督和蒸馏是否能改善这一问题。

建议正文包含：任务与问题、相关工作、密度与权重生成、尺度加权蒸馏、实验协议、对照和消融、效率、局限。可以采用工作标题“面向无人机视角的尺度感知知识蒸馏轻量级车辆计数”，在结果出来前不写“高精度”“最优”。

拟贡献应写成可核验的算法机制和实测效果，不把使用 UAVDT/CARPK、输出 HDF5 或替换计数对象写成独立重大创新。

## 11. 专利交底书具体准备

候选名称：一种尺度感知蒸馏的无人机车辆计数方法。

交底书写清：图像获取与预处理、车辆框解析、尺度参数计算、单位质量密度核生成、有界空间权重生成、教师训练、学生监督与特征蒸馏、学生推理计数。列出输入输出、变量、计算顺序、边界规则和一套可执行参数示例。

建议提供 5 张图：整体流程、密度图与权重图生成、教师学生结构、损失作用位置、推理输出。结果必须来自真实实验，不用计划中的效果填充实施例。

核心独立权利要求与从属权利要求的范围由代理师结合检索结果确定。核参数、限幅、分辨率对齐、权重作用层级和推理部署形式可作为具体实施细节讨论，不以单纯“先转标签再训练”作唯一核心。

本科/研究生学校考核只要求受理，不意味着可以省略说明书中的实施细节或虚构实验。补充新内容受到申请原始公开范围限制，应在第一次交底时充分说明已有可实施方案。
